EAS Update: Incremental OTA Updates Made Simple

📅 2026-11-03
Learn how Expo Application Services (EAS) Update delivers smaller, incremental over‑the‑air patches by sending only changed JavaScript and assets, cutting download time and improving user experience.
expo eas updates

Insight

Expo's EAS Update replaces the old "download‑the‑whole‑bundle" model with a diff‑based approach. When you publish a new version, EAS calculates the delta between the current client bundle and the new one, sending only the changed JS modules and assets. This incremental strategy shrinks payloads from megabytes to a few hundred kilobytes, dramatically speeding up cold‑start updates on flaky networks. It also respects the user's data plan by leveraging background fetch and only applying updates when the app is idle.

Example

import * as Updates from 'expo-updates';
import { useEffect, useState } from 'react';
import { View, Text, Button, ActivityIndicator } from 'react-native';

export default function UpdateChecker() {
  const [checking, setChecking] = useState(false);

  useEffect(() => {
    async function check() {
      setChecking(true);
      const update = await Updates.checkForUpdateAsync();
      if (update.isAvailable) {
        await Updates.fetchUpdateAsync();
        await Updates.reloadAsync(); // applies the incremental patch
      }
      setChecking(false);
    }
    check();
  }, []);

  return (
    <View>
      {checking ? <ActivityIndicator /> : <Text>App is up‑to‑date</Text>}
    </View>
  );
}

Takeaway

Enable EAS Update in your eas.json and let Expo handle diff generation. By checking for updates on launch (or in a background task), you deliver tiny patches that keep users on the latest code without the friction of a full reinstall.
