Prefetching Screens with React Query for Seamless Navigation

📅 2026-10-03
Use React Query's prefetch capabilities to load data before a screen appears, cutting perceived load time in React Native apps.
react-query performance react-native

Insight

When a user navigates to a detail screen, the UI often stalls while the data fetch resolves. React Query lets you prefetch that data during the previous screen's idle time, so the target screen can render instantly with cached results. This pattern reduces perceived latency without adding complex loading states.

Example

// In a list screen
import { useNavigation } from '@react-navigation/native';
import { useQueryClient, prefetchQuery } from '@tanstack/react-query';

function Item({ id }: { id: string }) {
  const navigation = useNavigation();
  const queryClient = useQueryClient();

  const handlePress = () => {
    // Prefetch the detail data while navigating
    prefetchQuery(['item', id], () => fetchItem(id));
    navigation.navigate('Detail', { id });
  };

  return <TouchableOpacity onPress={handlePress}>Open</TouchableOpacity>;
}

Takeaway

Trigger prefetchQuery right before navigation (or on hover in web) to warm the cache. The destination screen can then call useQuery(['item', id]) and instantly receive the cached payload, delivering a snappier user experience.
