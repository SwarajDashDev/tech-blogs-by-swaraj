Simplify Deep Linking with Expo Router’s File‑Based Routing

📅 2026-09-10
Learn how Expo Router’s file‑based routing removes the boilerplate of manual linking configuration in React Navigation, making deep links effortless.
expo router deeplinking

Insight

Expo Router treats the filesystem as your navigation map. Every screen file automatically becomes a route, and dynamic segments ([id].tsx) are parsed for you. This eliminates the verbose linking object you normally craft for React Navigation, reducing errors and keeping deep‑link handling in sync with your UI.

Example

// app/profile/[id].tsx
import { useLocalSearchParams } from 'expo-router';

export default function ProfileScreen() {
  const { id } = useLocalSearchParams<{ id: string }>();
  return <Text>Profile ID: {id}</Text>;
}

// Somewhere else in the app
import { router } from 'expo-router';
router.push('/profile/42'); // Opens the dynamic screen

The above works out‑of‑the‑box on iOS, Android, and web, with the correct URL (myapp://profile/42) generated for each platform.

Takeaway

When you need deep linking, prefer Expo Router’s file‑based approach. It auto‑generates the linking config, keeps routes type‑safe, and lets you focus on UI rather than navigation plumbing.
