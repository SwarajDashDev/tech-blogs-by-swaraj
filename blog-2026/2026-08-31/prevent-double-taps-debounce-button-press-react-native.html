Prevent Double Taps: Debounce Button Presses in React Native

📅 2026-08-31
A quick tip for eliminating accidental double‑taps on buttons by debouncing press handlers with a tiny custom hook.
react-native performance hooks

Insight

Accidental double‑taps are a common UX bug, especially on slower devices where a single tap may be interpreted as multiple presses. Instead of scattering setTimeout logic throughout your components, a reusable debounce hook keeps the code tidy and guarantees that only the first tap in a short window triggers the action. This pattern works for any touchable component—Button, Pressable, or custom touchables—without sacrificing responsiveness.

Example

import { useCallback, useRef } from 'react';
import { TouchableOpacity, Text } from 'react-native';

function useDebouncedPress(callback: () => void, delay = 300) {
  const timeout = useRef<NodeJS.Timeout | null>(null);
  return useCallback(() => {
    if (timeout.current) return; // ignore subsequent taps
    callback();
    timeout.current = setTimeout(() => (timeout.current = null), delay);
  }, [callback, delay]);
}

export default function SaveButton({ onSave }: { onSave: () => void }) {
  const handlePress = useDebouncedPress(onSave);
  return (
    <TouchableOpacity onPress={handlePress} style={{ padding: 12, backgroundColor: '#4caf50' }}>
      <Text style={{ color: '#fff' }}>Save</Text>
    </TouchableOpacity>
  );
}

Takeaway

Wrap your press handlers with a small debounce hook to guarantee idempotent UI actions. It eliminates duplicate network calls, prevents UI glitches, and keeps the component code clean—especially valuable in forms or checkout flows where a single accidental double‑tap can cause costly side effects.
