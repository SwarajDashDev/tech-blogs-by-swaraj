Lazy‑Load Screens in React Navigation to Shrink Bundle Size

📅 2026-09-02
Speed up app launch by loading screens only when they’re needed, using React.lazy and Suspense with React Navigation.
react-native navigation performance

Insight

When a React Native app grows, the initial JavaScript bundle can become a bottleneck. Instead of importing every screen up‑front, you can lazy‑load each route. React Navigation works seamlessly with React.lazy and Suspense, letting the bundle stay small while still providing a smooth navigation experience. This pattern is especially useful for rarely‑visited screens like settings or help pages.

Example

// navigation.tsx
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { Suspense } from 'react';
import LoadingScreen from './components/LoadingScreen';

const Stack = createNativeStackNavigator();

const HomeScreen = require('./screens/HomeScreen').default;
const SettingsScreen = React.lazy(() => import('./screens/SettingsScreen'));

export default function AppNavigator() {
  return (
    <Stack.Navigator>
      <Stack.Screen name="Home" component={HomeScreen} />
      <Stack.Screen
        name="Settings"
        // Wrap lazy component in Suspense
        component={() => (
          <Suspense fallback={<LoadingScreen />}> 
            <SettingsScreen />
          </Suspense>
        )}
      />
    </Stack.Navigator>
  );
}

Takeaway

Wrap each lazily imported screen in Suspense with a lightweight fallback. This drops unused code from the initial bundle, reduces startup time, and only loads the screen when the user navigates to it.
