Debounce API Calls in React Native with React Query and a useDebounce Hook

📅 2026-09-11
Learn how to prevent excessive network traffic by debouncing user input before triggering React Query fetches in a React Native app.
react query debounce react native

Insight

When building search or type‑ahead features in React Native, each keystroke can fire a new network request, quickly overwhelming your backend and draining battery. Combining a lightweight useDebounce hook with React Query’s enabled flag lets you wait for a pause in user input before issuing the request, keeping the UI responsive and the API load low.

Example

import { useState } from "react";
import { useQuery } from "@tanstack/react-query";
import { TextInput, FlatList, Text } from "react-native";

function useDebounce<T>(value: T, delay = 300): T {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

export default function SearchScreen() {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebounce(query);

  const { data, isLoading } = useQuery(
    ["search", debouncedQuery],
    () => fetch(`https://api.example.com/search?q=${debouncedQuery}`).then(r => r.json()),
    { enabled: !!debouncedQuery }
  );

  return (
    <>
      <TextInput placeholder="Search..." value={query} onChangeText={setQuery} />
      {isLoading ? <Text>Loading...</Text> : <FlatList data={data} renderItem={({item}) => <Text>{item.name}</Text>} />}
    </>
  );
}

Takeaway

Wrap the user‑controlled value in a debounce hook and feed the debounced result to React Query. The enabled option guarantees the fetch runs only after the pause, dramatically cutting down unnecessary calls while preserving a smooth typing experience.
