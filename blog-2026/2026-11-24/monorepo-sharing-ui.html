Monorepo Magic: Sharing UI Components Between React Native and Web

📅 2026-11-24
Learn how to set up a Yarn workspace monorepo so React Native and web projects can reuse the same UI components, reducing duplication and keeping styles consistent.
monorepo react native web

Insight

A monorepo with Yarn workspaces lets you keep a single source of truth for UI components used across React Native and web. By colocating shared code in a ui package and leveraging TypeScript path aliases, you avoid copy‑paste bugs and accelerate visual updates. The trick is to write components in a platform‑agnostic way and use file extensions like .native.tsx for RN‑specific code and .tsx for the web fallback.

Example

// packages/ui/tsconfig.json
{
  "compilerOptions": {
    "baseUrl": "src",
    "paths": {
      "@ui/*": ["*"]
    }
  }
}

// apps/mobile/App.tsx
import { Button } from "@ui/components";

export default function App() {
  return <Button title="Press me" onPress={() => console.log('tap')} />;
}

Takeaway

Structure your repo with a dedicated UI package, use TypeScript path aliases, and split platform‑specific implementations via file extensions. This yields a single, testable component library that powers both native and web builds with minimal friction.
