Lazy Loading Images with Expo Image for Faster RN Screens

📅 2026-08-25
Learn how Expo Image's built‑in lazy loading can dramatically reduce first‑paint time in React Native, especially for scrollable feeds.
react native expo performance

Insight

Expo Image (introduced in SDK 50) brings native‑level lazy loading and automatic caching to React Native. Unlike Image from react-native, it defers decoding until the component is on‑screen, cutting memory churn and speeding up initial renders. This is especially valuable in feed‑style screens where dozens of thumbnails compete for bandwidth.

Example

import { Image } from 'expo-image';

export default function PostThumbnail({ uri }: { uri: string }) {
  return (
    <Image
      source={{ uri }}
      style={{ width: 120, height: 120, borderRadius: 8 }}
      placeholder={require('../assets/placeholder.png')}
      contentFit="cover"
      transition={200} // fade‑in when loaded
    />
  );
}

The placeholder prop shows a local asset while the remote image loads, and transition adds a smooth fade‑in.

Takeaway

Swap react-native's Image for expo-image on any screen with many pictures. You’ll see lower memory usage, quicker UI paint, and a better perceived performance without extra libraries.
