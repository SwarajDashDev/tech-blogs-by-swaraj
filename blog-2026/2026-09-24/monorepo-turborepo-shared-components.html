Sharing UI Between React Native and Web with Turborepo

📅 2026-09-24
Learn how Turborepo lets you keep a single source of truth for UI components that work on both React Native and the web, reducing duplication and easing maintenance.
monorepo turborepo react native

Insight

Turborepo makes it trivial to house a shared UI package that can be imported from both a React Native app and a Next.js web front‑end. By leveraging react-native-web and Platform.select, you write the component once, keep styling consistent, and let the build pipeline generate the correct bundles for each platform. This approach eliminates the copy‑paste nightmare of maintaining parallel component trees while still allowing platform‑specific tweaks when needed.

Example

// packages/ui/src/Button.tsx
import { Platform, TouchableOpacity, Text } from 'react-native';

export const Button = ({ title, onPress }: { title: string; onPress: () => void }) => (
  <TouchableOpacity
    onPress={onPress}
    style={Platform.select({
      ios: { backgroundColor: '#0a84ff' },
      android: { backgroundColor: '#3ddc84' },
      default: { backgroundColor: '#0066ff', cursor: 'pointer' }, // web
    })}
  >
    <Text style={{ color: '#fff', padding: 10 }}>{title}</Text>
  </TouchableOpacity>
);

Takeaway

Put reusable UI in a separate Turborepo package, use Platform.select for minor differences, and let each app import the same component. You’ll ship fewer files, enjoy consistent design, and speed up iteration across mobile and web.
