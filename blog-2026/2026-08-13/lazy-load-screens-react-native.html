Lazy Load Screens in React Native to Shrink Bundle Size

📅 2026-08-13
Learn how to dynamically import screen components in a React Navigation stack to reduce the initial JavaScript bundle and improve startup time.
react native performance navigation

Insight

In most RN apps every screen is bundled up‑front, even if a user never visits half of them. By leveraging JavaScript's import() with React.lazy and the experimental Suspense support in React Native, you can defer loading of heavy screens until they’re actually needed. This pattern mirrors web code‑splitting and can shave 30‑50 KB off the initial bundle, leading to faster launches on low‑end devices.

Example

// navigation.tsx
import {createNativeStackNavigator} from '@react-navigation/native-stack';
import React, {Suspense} from 'react';
import {ActivityIndicator} from 'react-native';

const Stack = createNativeStackNavigator();
const HomeScreen = React.lazy(() => import('./screens/HomeScreen'));
const SettingsScreen = React.lazy(() => import('./screens/SettingsScreen'));

export default function AppNavigator() {
  return (
    <Suspense fallback={<ActivityIndicator size="large" />}> 
      <Stack.Navigator>
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Settings" component={SettingsScreen} />
      </Stack.Navigator>
    </Suspense>
  );
}

Takeaway

Wrap lazily loaded screens in a Suspense boundary and use React.lazy with import(). The first render stays lightweight, and each screen’s code is fetched only when the user navigates to it, giving a noticeable startup boost without sacrificing navigation experience.
