Optimistic UI Updates with React Query in React Native

📅 2026-11-13
Leverage React Query's optimistic updates to make your React Native app feel instantly responsive, even before the server confirms changes.
react-native react-query optimistic-updates

Insight

When a user performs a mutation—like toggling a favorite or adding a comment—waiting for the network round‑trip can make the UI feel sluggish. React Query’s optimistic update pattern lets you immediately reflect the change in the cache, roll back on error, and keep the UI snappy. This approach works seamlessly in React Native, where perceived performance is critical.

Example

// useToggleFavorite.ts
import {useMutation, useQueryClient} from '@tanstack/react-query';
import axios from 'axios';

export const useToggleFavorite = (itemId: string) => {
  const qc = useQueryClient();
  return useMutation(
    () => axios.post(`/items/${itemId}/favorite`),
    {
      // Optimistically flip the flag in the cached list
      onMutate: async () => {
        await qc.cancelQueries(['items']);
        const previous = qc.getQueryData<any[]>(['items']);
        qc.setQueryData(['items'], old =>
          old?.map(i => i.id === itemId ? {...i, favorite: !i.favorite} : i)
        );
        return {previous};
      },
      // Roll back on failure
      onError: (_err, _vars, context) => {
        qc.setQueryData(['items'], context?.previous);
      },
      // Refetch to sync with server
      onSettled: () => qc.invalidateQueries(['items']),
    }
  );
};

Takeaway

Wrap your mutation with onMutate, onError, and onSettled. Update the cache instantly, revert if the request fails, and finally refetch to ensure consistency. This pattern gives users immediate feedback while keeping data reliable.
