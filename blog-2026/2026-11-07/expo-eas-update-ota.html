Effortless OTA Updates with Expo EAS Update

📅 2026-11-07
Learn how to enable over‑the‑air updates in an Expo app using EAS Update, avoiding full rebuilds and keeping users on the latest code.
expo eas ota

Insight

Expo's EAS Update turns OTA updates from a manual hack into a first‑class feature. Unlike classic expo-updates which requires a custom server, EAS Update integrates with the EAS Build pipeline, automatically publishing a new bundle whenever you run eas update. The runtime checks for a newer bundle at launch (or on demand) and swaps it without reinstalling the native binary, dramatically reducing release friction.

Example

// app.tsx – trigger a manual check on a button press
import * as Updates from 'expo-updates';
import { Button, Alert } from 'react-native';

export default function App() {
  const checkForUpdates = async () => {
    const { isAvailable } = await Updates.checkForUpdateAsync();
    if (isAvailable) {
      await Updates.fetchUpdateAsync();
      await Updates.reloadAsync();
    } else {
      Alert.alert('No updates', 'You are on the latest version');
    }
  };

  return <Button title="Check for OTA" onPress={checkForUpdates} />;
}

Add the following to eas.json to enable automatic updates on every build:

{
  "cli": { "version": ">= 3.0.0" },
  "build": { "development": { "distribution": "internal" } },
  "submit": {},
  "update": { "fallbackToCacheTimeout": 0 }
}

Takeaway

Configure EAS Update once, then push code changes with eas update—no app store review needed. Pair it with a silent check on app launch for a seamless user experience, but always provide a manual "Check for updates" button for power users or critical patches.
